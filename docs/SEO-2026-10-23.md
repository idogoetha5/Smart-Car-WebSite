# Organic search: measured baseline and first implementation

## Evidence, not a ranking guarantee

Search Console read on 2026-10-23: indexing data last updated 2026-10-16,
150 indexed / 569 excluded. Breakdown: 186 alternate canonical, 183 redirect,
6 noindex (admin sign-in/unsubscribe), 6 404 (old fonts/malformed paths),
3 redirect errors last crawled August 4 (apex branch URLs), 123 discovered
not indexed, 53 Google-selected different canonical, 9 crawled not indexed
(fonts/favicons). These totals predate the October 22 partial-export incident.
Do not interpret every exclusion as a lost sales page or unblock private pages.

Search performance September 24–October 21 vs August 27–September 23:
249 vs 164 clicks; roughly 10.6K vs 7.92K impressions; average position 16.7 vs
24.2. Exact query “השכרת רכב בתל אביב”: 276 impressions, 0 clicks, position 9;
mobile 139/0/6.7, desktop 137/0/11.4. The only page is
`/he/branches/telaviv`. The report alone does not establish why nobody clicked.

Read-only audit of all 326 live sitemap URLs: zero HTTP failures, missing
titles, H1 count errors, self-canonical mismatches, noindex entries or missing
he/en language pairs. 114 vehicle URLs have empty descriptions; 46 title
duplicate groups and 38 description duplicate groups. `/catalog` has 45 rental
detail links in initial HTML per locale; `/rental` has none before rendering JS.
Audit tool: `node scripts/seo/audit.mjs --out=/tmp/smartcar-seo.json`.
This scans public HTML only; it is not a browser-rendered performance or ranking test.

## First change set (local until publisher records verification)

- Branch-specific bilingual titles, descriptions and share metadata, with the
  same description visible on each page. Retain all existing copy, FAQs,
  navigation, contacts, images and URLs. Add practical location/vehicle/period
  advice and server-rendered service links with 48px phone targets.
- Daily/hourly/monthly service advice, distinct search intent and correct
  social metadata for all service types. No invented hourly rate, included
  insurance or guaranteed availability.
- Every vehicle uses model/seats/transmission metadata, including records
  whose editorial description is empty. No year or daily calculation base in
  search copy; pricing and source vehicle descriptions are not mutated.
- National rental guidance and crawlable branch/service links below the
  existing results, preserving the booking and catalogue interaction.
- Leasing comparison guidance (term, annual mileage and quote-specific
  inclusions); global monthly/hourly footer links with 44px targets. Fixed
  the pre-existing duplicate React key for the two leasing footer labels.
- Only genuinely edited branch/service/rental sitemap modification dates
  change. No URL removed; no mass fresh dates on untouched content.

Local verification: 32 focused tests pass; a full run before the final
incomplete-record guard/footer change passed 1,108 tests in 85 files.
Typecheck and scoped lint pass. Browser at 360x800 verified Tel Aviv Hebrew,
Jerusalem English, hourly English, monthly Hebrew and leasing Hebrew: no
horizontal overflow, visible advice and 50px advice links. Actual client
navigation Tel Aviv → monthly succeeded. This is not production verification.
Local fixture vehicle records lack real make/model fields, so their detail
pages cannot establish production metadata correctness; live audit after
publication is mandatory. Incomplete records omit unknown specifications,
never inventing manual transmission or showing 'undefined'.
