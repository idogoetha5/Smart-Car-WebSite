# Google Sheets — טפסי תל אביב

החיבור מוסיף כל טופס חדש של סניף תל אביב לגיליון באופן מיידי, בנוסף לשמירה ב-Supabase ובאדמין.

## אמינות

- מזהה הטופס נשמר בעמודה הראשונה ומשמש למניעת שורות כפולות.
- האתר מבצע עד שלושה ניסיונות מיידיים.
- לפני השליחה נוצרת רשומה בטבלת `customer_sheet_outbox`.
- הצלחה מוחקת את הרשומה; כשל זמני נשאר לניסיון חוזר אוטומטי.
- רק `branchId=telaviv` נשלח ל-Google Sheets.

## רכיבים

- `AppsScript.gs` — קוד ה-Web App המחובר לגיליון.
- `database/migrations/add-customer-sheet-outbox.sql` — תור הניסיונות החוזרים.
- משתני Vercel סודיים: `CUSTOMER_SHEETS_WEBHOOK_URL`, `CUSTOMER_SHEETS_WEBHOOK_SECRET`.

## הפעלה חד-פעמית בגיליון

1. בגיליון פותחים **תוספים → Apps Script**.
2. מחליפים את כל תוכן `Code.gs` בתוכן הקובץ `AppsScript.gs` ושומרים.
3. פותחים **הגדרות הפרויקט → Script properties** ומוסיפים מאפיין בשם `WEBHOOK_SECRET` עם ערך סודי ארוך.
4. בוחרים **פריסה → פריסה חדשה → אפליקציית אינטרנט**.
5. מגדירים **הפעלה בתור: אני** ו-**למי יש גישה: כולם**, מאשרים ומעתיקים את כתובת אפליקציית האינטרנט.

אין צורך להכין עמודות ידנית. השליחה הראשונה יוצרת לשונית בשם `טפסי תל אביב`, מוסיפה את הכותרות ומעצבת אותן.
