# טפסי לקוחות - Smart Car

התיקייה מרכזת את כל החומרים שנוצרו עבור מערכת טפסי הלקוחות בתאריך 28.09.2026.

> ⛔ **אסור לשנות את הברקודים לעולם.** הם כבר מודפסים ומוצבים בסניפים. ראו הסבר מלא ב-`README.md` הראשי.

## מבנה התיקייה

- `QR/` - ארבע תמונות QR, אחת לכל סניף.
- `חוברות להדפסה/` - ארבעה קובצי PDF נפרדים להדפסה, בשם הסניף המתאים.
- `מסד נתונים/` - קובץ יצירת טבלת `customer_details_forms` ב-Supabase.
- `כלים/` - כלי יצירת חוברות ה-QR ופיצולן לקבצים נפרדים.
- `קוד מקור/` - צילום מצב של כל קובצי הקוד הקשורים לטופס, ל-API ולאדמין.
- `הוראות-הקמה.md` - הוראות הגדרה, כתובות מייל לפי סניף ותחזוקה עתידית.
